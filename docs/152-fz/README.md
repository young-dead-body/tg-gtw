## Согласование «document_version»

Версия документа «Согласие» (`consent.md`) соответствует ключу **`consent.document_version`**
в настройках Сервиса (при отсутствии значения используется `1.0`). Пользователь подтверждает
именно эту версию при нажатии «Принять».

Изменив текст согласия/политики происходим bump версии (например `1.1`), обновляя значение
`consent.document_version` в настройках; система потребует повторного согласия (несовпадение
версии).
