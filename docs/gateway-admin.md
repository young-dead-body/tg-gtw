# Администратор и пользователи

Первого администратора API создаёт автоматически при пустой БД. Случайные
`BOOTSTRAP_ADMIN_EMAIL` и `BOOTSTRAP_ADMIN_PASSWORD` установщик печатает в
консоль. В `.env` пароль администратора не задаётся. Если вывод потерян,
ищите эти строки в `docker compose logs api`. Они появляются только при
первом создании учётки.

Для смены пароля через панель откройте «Пользователи», выберите учётку и
задайте новый пароль. Если доступ к панели утрачен, используйте единственный
скрипт управления пользователями:

```bash
sudo ./scripts/userctl.sh admin-0123456789abcdef@example.com --role admin --password 'НовыйСложныйПароль' --unblock
```

Подставьте свой адрес администратора. Если его нет в логах, найдите в БД:

```bash
docker compose exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "SELECT email FROM users WHERE role = '\''admin'\'';"'
```

Создание пользователя:

```bash
sudo ./scripts/userctl.sh ivan@example.com --role user --password 'СложныйПароль' --first Иван --last Иванов
```

`./scripts/userctl.sh --help` показывает остальные параметры. Скрипт
хеширует пароль Argon2id, обновляет историю паролей и может снять блокировку.
Не передавайте пароль в общедоступной истории команд или журналах.
